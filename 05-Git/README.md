# Git – Version Control

## Introduction

Git is a distributed version control system used to track changes in files over time. It allows developers to maintain different versions of a project, recover previous versions, and work on different features independently.

## What Is Version Control?

Version control is a system that records changes made to files over time.

It helps developers:

- Track modifications.
- Identify when changes were made.
- Restore previous versions.
- Work collaboratively.
- Maintain an organized project history.

## Git vs GitHub

| Git | GitHub |
|---|---|
| Version control system. | Online hosting platform. |
| Works locally on a computer. | Hosts remote repositories. |
| Tracks project changes. | Supports sharing and collaboration. |
| Can work offline. | Online features require internet access. |

## Types of Version Control Systems

1. **Local Version Control:** Maintains versions on a single computer.
2. **Centralized Version Control:** Stores project history on a central server.
3. **Distributed Version Control:** Each repository contains its own project history. Git is an example.

## Important Git Concepts

- **Repository:** A location where project files and their history are stored.
- **Commit:** A saved snapshot of changes.
- **Branch:** An independent line of development.
- **Merge:** Combines changes
