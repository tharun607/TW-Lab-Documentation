# Assignment – Google Docs

## Introduction

Google Docs is an online word-processing application provided by Google. It allows users to create, edit, format, and share documents through a web browser. Multiple users can work on the same document in real time.

## Key Features

- **Real-time collaboration:** Multiple users can edit a document simultaneously.
- **Formatting:** Supports headings, paragraphs, tables, images, lists, and equations.
- **Comments and suggestions:** Allows reviewers to provide feedback without directly changing the original content.
- **Version history:** Automatically saves changes and allows users to view or restore previous versions.
- **Sharing and permissions:** Documents can be shared with Viewer, Commenter, or Editor access.
- **Export options:** Documents can be downloaded in formats such as PDF, DOCX, ODT, and HTML.

## Creating and Structuring Documents

Google Docs allows users to create documents from a blank page or from predefined templates.

Documents can be organized using paragraph styles such as:

- Title
- Subtitle
- Heading 1
- Heading 2
- Normal Text

Using headings consistently helps maintain a clear document structure and allows an automatic table of contents to be generated.

## Collaboration and Sharing

Documents can be shared through email invitations or links. Different access permissions can be assigned:

- **Viewer:** Can only view the document.
- **Commenter:** Can view and add comments.
- **Editor:** Can make changes to the document.

The Suggesting mode allows collaborators to propose edits without directly modifying the original text.

## Version History

Google Docs automatically saves document changes. The Version History feature, available under **File → Version history**, allows users to:

- View earlier versions of a document.
- Identify changes made over time.
- Restore a previous version.
- Name important versions for easier identification.

## Additional Documentation Features

Google Docs also supports:

- Inserting images, drawings, and diagrams.
- Creating tables, bulleted lists, and numbered lists.
- Adding mathematical equations.
- Using headers, footers, and page numbers.
- Adding citations and generating bibliographies.
- Exporting documents into different file formats.

## Doxygen and Google Docs

Doxygen and Google Docs serve different documentation purposes.

| Doxygen | Google Docs |
|---|---|
| Primarily used for source-code documentation. | Used for general-purpose documents. |
| Generates documentation from source-code comments. | Documents are written and formatted manually. |
| Commonly generates HTML and LaTeX output. | Supports formats such as PDF and DOCX. |
| Useful for API and software documentation. | Useful for reports, proposals, and collaborative writing. |

Both tools can be used together to document different aspects of a software project.

## Practical Activity

The course material suggests performing the following activities:

1. Create a Google Docs document.
2. Share it with a classmate using editing or suggesting permissions.
3. Experiment with headings, comments, and suggestions.
4. Insert a table and an image or diagram.
5. Explore Version History and restore an earlier version.

## Best Practices

- Use consistent heading styles and formatting.
- Organize content with clear sections.
- Assign appropriate sharing permissions.
- Resolve comments and review suggestions.
- Use version history to track important changes.
- Export or back up important documents when necessary.
